# CustomChat

Консольный чат на Node.js. Каждый запрос отправляет модели всю переписку текущей сессии и печатает полный ответ после завершения генерации. Потоковая выдача не используется.

Требуется Node.js 22 или новее.

## Запуск

1. Установи зависимости: `npm install`.
2. Если `.env` ещё нет, скопируй `.env.example` в `.env`.
3. Создай API-ключ Groq в [консоли Groq](https://console.groq.com/keys) и вставь его после `GROQ_API_KEY=` в `.env`.
4. Запусти чат: `npm start`.

Файл уже загружается при запуске. Его формат:

```dotenv
GROQ_API_KEY=твой-ключ-Groq
# Необязательно: можно выбрать другую доступную модель Groq
GROQ_MODEL=openai/gpt-oss-20b
```

По умолчанию используется `openai/gpt-oss-20b`. Модель можно переопределить через `GROQ_MODEL`. Бесплатный план Groq ограничен квотами; при их превышении API временно отклоняет запросы.

## Интерфейс адаптера

`getTextResponse(messages)` из `groq-adapter.mjs` принимает список сообщений `{ role, content }` и возвращает `Promise<string>` с полным ответом. Адаптер использует OpenAI JS SDK с совместимым Responses API Groq и сохраняет локальное выполнение файловых инструментов.

Responses API Groq находится в beta; формат и доступность функций могут измениться.

## Память диалогов

При запуске создаётся новая сессия и отдельный файл `memory/session-<дата>-<id>.json`. Модуль `memory-repository.mjs` хранит сообщения в памяти процесса и сохраняет их в файл после каждого сообщения. При каждом запросе модели передаётся вся переписка текущей сессии. Файлы предыдущих запусков остаются в `memory/`, но автоматически не загружаются. Команда `/clear` начинает новую сессию в другом файле. Папка `memory/` исключена из Git.

## Файловые инструменты

Модель может вызвать `create_file` или `read_file`, когда ты просишь её создать или прочитать текстовый файл. Например: «Создай `notes.txt` с моими заметками» или «Прочитай `notes.txt`». Инструменты работают только внутри `workspace/`, принимают относительные пути и не перезаписывают существующие файлы. Подкаталоги создаются автоматически; размер файла ограничен 256 KiB. Абсолютные пути, выход за пределы `workspace/` и символические ссылки запрещены. Содержимое прочитанного файла передаётся модели для ответа.

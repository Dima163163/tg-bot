# CustomChat

Консольный чат на Node.js. Каждая введённая строка отправляется модели как один промпт, а полный текстовый ответ печатается после завершения генерации. История переписки и потоковая выдача пока не используются.

Требуется Node.js 22 или новее.

## Запуск

1. Установи зависимости: `npm install`.
2. Открой `.env` и вставь ключ после `OPENAI_API_KEY=`. Если `.env` ещё нет, скопируй `.env.example` в `.env`.
3. Запусти чат: `npm start`.

Файл уже загружается при запуске. Его формат:

```dotenv
OPENAI_API_KEY=твой-ключ
# Необязательно: можно выбрать другую модель
OPENAI_MODEL=gpt-6-luna
```

По умолчанию используется модель `gpt-6-luna`. Её можно переопределить через `OPENAI_MODEL`.

## Интерфейс адаптера

`getTextResponse(prompt)` из `openai-adapter.mjs` принимает одну строку и возвращает `Promise<string>` с полным ответом. Подробности запроса к OpenAI API остаются внутри адаптера.

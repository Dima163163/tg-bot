# 0002. Включить Supabase Realtime для сообщений

- Status: Accepted
- Date: 2026-10-08

## Context

Веб-панель читает клиентов и сообщения через Edge Functions. Сейчас её запросы обновляются каждые 30 секунд и вручную. Для будущего получения событий о новых сообщениях таблица `public.messages` должна входить в публикацию `supabase_realtime`.

Текущие endpoints чтения уже публичны. Чтобы анонимный клиент мог получать события Realtime, ему также предоставляется чтение строк `messages` через RLS.

## Decision

Включить `public.messages` в публикацию `supabase_realtime` и разрешить роли `anon` читать строки этой таблицы. Панель пока продолжает использовать периодические запросы и ручное обновление; эта запись фиксирует настройку базы и не утверждает, что клиентская Realtime-подписка уже реализована.

## Consequences

- Анонимный клиент может читать все строки `messages` через Data API и подписываться на события этой таблицы. В ней нельзя хранить данные, которые должны быть закрыты от публичного доступа.
- До добавления Realtime-подписки в панель новые сообщения по-прежнему появляются после очередного опроса или ручного обновления.
- SQL для ручной настройки проекта и миграция должны сохранять одинаковые настройки публикации и RLS.
